This is a sample Cypress Project
🚀 Overview

This project contains an end-to-end test automation framework built using Cypress.
It is designed for UI automation, API testing, component testing, and can be executed locally or in a CI/CD pipeline.

The framework follows best practices such as:

Page Object / App Actions Pattern

Reusable custom commands

Centralized configuration

Rich reporting (Allure / Mochawesome)

Parallel execution support

🛠️ Tech Stack

Cypress (UI + API Testing)

Node.js (Runtime)

Mocha (Test Runner)

Chai (Assertions)

TypeScript / JavaScript (Depending on project setup)

Allure / Mochawesome for reporting

GitHub Actions / Jenkins / Azure DevOps for CI
